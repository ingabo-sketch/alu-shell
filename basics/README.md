# basics

Scripts for Shell, basics.

- 0-current_working_directory: prints the absolute path of the current working directory
- 1-listit: lists the current directory
- 2-bring_me_home: changes to the home directory
- 3-listfiles: lists the current directory in long format
- 4-listmorefiles: lists the current directory in long format, including hidden files
- 5-listfilesdigitonly: lists in long format with numeric user and group IDs, including hidden files
- 6-firstdirectory: creates /tmp/my_first_directory
- 7-movethatfile: moves /tmp/betty into /tmp/my_first_directory
- 8-firstdelete: deletes /tmp/my_first_directory/betty
- 9-firstdirdeletion: deletes /tmp/my_first_directory
- 10-back: returns to the previous working directory
- 11-lists: lists the current directory, its parent, and /boot in long format, including hidden files
- 12-file_type: prints the type of /tmp/iamafile
- 13-symbolic_link: creates a symbolic link __ls__ to /bin/ls
- 14-copy_html: copies newer or missing HTML files to the parent directory
- 15-lets_move: moves files starting with an uppercase letter to /tmp/u
- 16-clean_emacs: deletes files ending with ~
- 17-tree: creates welcome/to/school
