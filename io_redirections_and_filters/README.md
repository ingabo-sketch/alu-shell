# Shell, I/O Redirections and filters

Scripts for redirections, filters, and text processing.

- `0-hello_world`: prints Hello, World
- `1-confused_smiley`: prints a confused smiley
- `2-hellofile`: displays /etc/passwd
- `3-twofiles`: displays /etc/passwd and /etc/hosts
- `4-lastlines`: displays the last 10 lines of /etc/passwd
- `5-firstlines`: displays the first 10 lines of /etc/passwd
- `6-third_line`: displays the third line of iacta
- `7-file`: creates a file with a special name containing Best School
- `8-cwd_state`: saves ls -la into ls_cwd_content
- `9-duplicate_last_line`: duplicates the last line of iacta
- `10-no_more_js`: deletes regular files ending in .js
- `11-directories`: counts directories and subdirectories
- `12-newest_files`: lists the 10 newest files
- `13-unique`: prints words that appear exactly once, sorted
- `14-findthatword`: displays lines containing root in /etc/passwd
- `15-countthatword`: counts lines containing bin in /etc/passwd
- `16-whatsnext`: displays lines containing root and the next 3 lines
- `17-hidethisword`: displays lines of /etc/passwd that do not contain bin
- `18-letteronly`: displays lines of sshd_config that start with a letter
- `19-AZ`: replaces A with Z and c with e
- `20-hiago`: removes every c and C
- `21-reverse`: reverses its input
- `22-users_and_homes`: lists users and home directories, sorted
- `23-empty_casks`: lists empty files and directories by name
- `24-gifs`: lists .gif files without the extension
- `25-acrostic`: prints the first letter of each line
- `26-the_biggest_fan`: prints the 11 hosts with the most requests
