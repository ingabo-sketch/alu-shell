# Shell, loops, conditions and parsing

- `1-for_best_school`: displays Best School 10 times with for
- `2-while_best_school`: displays Best School 10 times with while
- `3-until_best_school`: displays Best School 10 times with until
- `4-if_9_say_hi`: displays Best School 10 times and Hi on the 9th
- `5-4_bad_luck_8_is_your_chance`: prints bad luck, good luck, or Best School
- `6-superstitious_numbers`: displays 1 to 20 with case messages
- `7-clock`: displays hours 0 to 12 and minutes 1 to 59
- `8-for_ls`: lists filenames after the first dash
- `9-to_file_or_not_to_file`: reports whether school exists, is empty, and is regular
- `10-fizzbuzz`: prints FizzBuzz from 1 to 100
- `11-read_and_cut`: displays username, user id, and home from /etc/passwd
- `12-tell_the_story_of_passwd`: tells the /etc/passwd story
- `13-lets_parse_apache_logs`: displays IP and HTTP code from the Apache log
- `14-dig_the-data`: groups Apache log visitors by IP and HTTP code
