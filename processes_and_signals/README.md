# Shell, processes and signals

- `0-what-is-my-pid`: displays the script PID
- `1-list_your_processes`: lists all processes in a hierarchy
- `2-show_your_bash_pid`: shows processes whose listing contains bash
- `3-show_your_bash_pid_made_easy`: shows bash PIDs and names
- `4-to_infinity_and_beyond`: prints a message forever
- `5-dont_stop_me_now`: stops 4-to_infinity_and_beyond with kill
- `6-stop_me_if_you_can`: stops 4-to_infinity_and_beyond with pkill
- `67-stop_me_if_you_can`: stops 7-highlander with pkill
- `7-highlander`: prints forever and answers SIGTERM
- `8-beheaded_process`: kills 7-highlander
- `10-process_and_pid_file`: stores its PID and handles signals
- `manage_my_process`: writes I am alive! every 2 seconds
- `11-manage_my_process`: starts, stops, and restarts manage_my_process
